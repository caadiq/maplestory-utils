# 해상도별 기준 스크린샷

재획 타이머(`/timer`)의 퀵슬롯 자동 탐색이 쓰는 계산식을 뽑아낸 원본입니다.
게임 설정의 해상도 6종을 **창모드**로 찍었고, 게임 자체 스크린샷 기능이라
창 테두리 없이 게임 화면만 담겨 있습니다.

## 여기서 얻은 규칙

```
UI 배율     = max(1, 캡처 세로 ÷ 768)
아이콘 크기  = 32 × 배율
퀵슬롯 상자  = 우하단에서 600 × 110 × 배율
```

실측값 (야누스 아이콘, 우하단 모서리 기준):

| 해상도 | 배율 | 아이콘 | 위치 (dx, dy) |
|---|---|---|---|
| 1024×768 | 1.000 | 32px | (175, 45) |
| 1280×720 | 1.000 | 32px | (175, 45) |
| 1366×768 | 1.000 | 32px | (175, 45) |
| 1920×1080 | 1.406 | 46px | (246, 64) |
| 1920×1200 | 1.563 | 50px | (274, 70) |
| 2560×1440 | 1.875 | 60px | (328, 84) |

> 세로 720은 768보다 작지만 UI가 축소되지는 않아 배율 1로 둡니다.
> 전체화면으로 확대돼도 화면째 늘어나므로 캡처 세로로 계산하면 그대로 맞습니다.

## 언제 다시 쓰나

- 탐색 코드(`frontend/src/features/timer/locateCore.js`)를 손댈 때 회귀 확인용
- 게임 UI 개편으로 퀵슬롯 위치나 크기가 바뀌었을 때 다시 재는 기준

확인 방법: 이 이미지를 화면 공유 스트림 대신 넣고 `/timer`에서 자동 탐색을 돌려,
잡힌 위치가 위 표와 맞는지 본다.
