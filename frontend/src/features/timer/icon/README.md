# 야누스 아이콘 원본

여기 있는 이미지들로 화면에서 야누스 아이콘 자리를 찾습니다.
한 번도 영역을 지정하지 않은 상태에서도 자동으로 찾습니다.

## 파일 구성

| 이름 | 쓰임 |
|---|---|
| `janus-dawn.png` / `janus-dusk.png` | 게임 리소스 원본. **모드 판별**은 이 둘로만 한다 |
| `janus-cooldowndusk1~2.png` | 황혼 쿨타임 중 실물 (쿨 3초라 숫자가 1·2뿐) |
| `janus-cooldowndawn00~47.png` | 새벽 쿨타임 중 실물 48장 |

`janus-*` 로 시작하면 파일만 넣어도 탐색에 자동으로 들어갑니다.
이름이 `cooldown`으로 시작하면 **자리 찾기·채점에만 쓰고 모드 판별에는 안 씁니다**
(쿨타임 모습은 어느 모드인지 알려주지 못하므로).

## 왜 쿨타임 모습을 이렇게 많이 넣나

쿨타임 중에는 아이콘 가운데에 **노란 숫자**가 얹히고 주변이 어두워져, 원본과의
일치도가 0.26~0.44까지 떨어집니다. 후보 통과선(0.45) 아래라 **아예 못 찾습니다.**
숫자는 매초 바뀌므로 한두 장으로는 어느 순간에도 안 맞습니다.

실측(10분 영상 2편, 612프레임)으로 확인한 차이:

| 템플릿 | 1위 정답 | 바로 확정 | 잘못 확정 |
|---|---|---|---|
| 8장 | 95.1% | 83.2% | 0 |
| **52장** | **99.2%** | **98.9%** | **0** |

템플릿을 늘려도 느려지지 않는 이유는 `locateCore.js`가 **자리 찾기와 채점을 나눠**
두기 때문입니다 — 채점은 자리마다 작은 창의 내적 한 번이라 장수에 거의 영향받지 않습니다.

## 다시 만드는 법

영상에서 아이콘 자리만 잘라내 서로 충분히 다른 것들만 고르면 됩니다.
(고를 때 "자기와 닮은 프레임이 여러 개 있는 것"만 남겨야 합니다 — 데미지 숫자가
아이콘을 덮은 순간이나 섬광으로 하얗게 날아간 순간이 섞이면 그게 아무 데나 맞는
쓰레기 템플릿이 됩니다.)

```bash
ffmpeg -i 재획영상.mp4 -vf "crop=44:44:1675:1017,fps=2" crop/%04d.png
```

- 크롭은 **아이콘이 실제로 보이는 크기 그대로** 뜨세요. 다른 배율은 알아서 맞춥니다.
- 다만 **작게 떠서 키우는 쪽이 손해**입니다 — 실측에서 35px로 뜬 템플릿을 44px 화면에
  대면 일치도가 0.50까지 떨어졌고, 반대(44px → 35px)는 0.75를 지켰습니다.
  가능하면 아이콘이 큰 화면에서 뜨세요.

한 번 직접 지정하고 나면 그때의 모양이 저장되고, 이후에는 그쪽을 우선 씁니다
(사용자 화면에서 실제로 보이는 모습이라 더 정확합니다).
