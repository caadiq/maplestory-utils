# 야누스 아이콘 원본

여기에 야누스 스킬 아이콘 이미지(png/webp)를 넣으면,
한 번도 영역을 지정하지 않은 상태에서도 화면에서 자동으로 찾습니다.

```bash
cp janus.png src/features/janus/icon/
docker compose up -d --build frontend
```

- 파일은 하나만, 파일명은 영문으로 두세요 (여러 개면 첫 번째만 씁니다).
- 게임에서 보이는 그대로가 가장 좋습니다. 퀵슬롯 테두리는 없어도 됩니다.
- 화면 배율이 달라도 되도록 여러 크기로 훑기 때문에 크기는 크게 신경 쓰지 않아도 됩니다.

한 번 직접 지정하고 나면 그때의 모양이 저장되고, 이후에는 그쪽을 우선 씁니다
(사용자 화면에서 실제로 보이는 모습이라 더 정확합니다).
