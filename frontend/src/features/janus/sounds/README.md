# 야누스 알림 소리 파일

이 폴더에 mp3(또는 ogg/wav/m4a)를 넣고 다시 빌드하면 **자동으로** 알림 소리 목록에 뜹니다.
코드는 건드릴 필요 없습니다.

```bash
cp 새소리.mp3 src/features/janus/sounds/
docker compose up -d --build frontend
```

이름표는 파일명 순서대로 "알림 1, 알림 2, …"가 붙습니다.
저장되는 값은 파일명이라, 나중에 파일을 추가해서 번호가 밀려도
이미 골라둔 소리는 그대로 유지됩니다.

## 고를 때

- **1~2초**가 적당합니다. 길면 다음 젠을 도는 동안 계속 울립니다.
- 앞쪽 무음은 신경 쓰지 않아도 됩니다 — 재생할 때 자동으로 건너뜁니다.
